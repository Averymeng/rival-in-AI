执行摘要

可灵凭运动/物理仿真与 4K 在专业与 B 端站稳，是国内 AI 视频生成的第一梯队。
国内最大对手是字节即梦，凭抖音生态获得碾压式用户规模。
Runway 仍是全球专业标杆，但商业化规模偏小。
海螺视频以性价比、Pika 以编辑玩法、PixVerse 以病毒模板各切一块。
Sora 关停后，赛道进入工业化拐点，竞争从「能不能生成」转向「生成可控+工作流」。

市场概览

AI 视频生成赛道 2024–2025 高速扩张，玩家分三层：巨头系（即梦/可灵，靠母生态流量）、专业工具系（Runway/Pika，靠模型与编辑能力）、性价比/病毒系（海螺视频/PixVerse）。来源：行业报道、公开财报。

产品定位

- 可灵：专业创作者 + 电商/营销生产力，强调「物理真实」与「可控」。

- 即梦：大众 + 字节系内容创作者，强调「免费 + 一键」。

- Runway：影视/设计专业人士，强调「创作自由度」。

- 海螺视频：中小团队，强调「性价比」。

- Pika：个人玩家，强调「好玩 + 编辑」。

- PixVerse：社媒创作者，强调「模板 + 病毒」。

维度热力矩阵

商业模式

- 可灵：免费 + 高级会员（按生成额度/清晰度分层），B 端 API 按量。

- 即梦：免费为主，嵌入剪映/豆包生态变现。

- Runway：订阅制（Standard/Pro/Unlimited），专业定价偏高。

- 海螺视频：免费 + 低门槛会员，靠 MiniMax 生态。

- Pika / PixVerse：免费 + 轻会员，靠玩法/模板拉新。

增长与运营

- 可灵：借快手/短视频达人内容裂变，B 端靠案例营销。

- 即梦：字节全域流量分发，规模碾压。

- Runway：专业社区 + 影视合作背书。

- 其余：社媒模板、KOL 共创为主。

竞争格局

国内「即梦 vs 可灵」双雄格局，海外 Runway 守专业高地。可灵的优势在物理仿真与 4K，短板在海外与端侧。来源：公开报道，未查证具体 MAU 数值。

SWOT

- 优势（S）：运动仿真领先、4K、快手数据壁垒、免费策略。

- 劣势（W）：海外弱、端侧/隐私对话缺失、尚未深度商业化。

- 机会（O）：多模态 Agent 工作流、企业知识库集成。

- 威胁（T）：即梦生态碾压、Sora 类巨头随时回归、算力成本压力。
