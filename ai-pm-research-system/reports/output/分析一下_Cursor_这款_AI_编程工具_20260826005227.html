02
MARKET OVERVIEW

市场概览

赛道格局与竞争梯队

AI 编程工具市场正处于爆发式增长阶段，从早期的代码补全（如 TabNine）演进到 AI Agent 驱动的自动化编程。Cursor 作为「AI 原生编辑器」的代表，与 GitHub Copilot（插件形态）、Windsurf（独立编辑器）、Cline（开源 Agent）等形成差异化竞争。市场呈现以下特征：

从辅助到自主：工具能力从「建议代码」向「理解项目、自主执行多文件任务」演进。

模型能力是核心壁垒：对前沿模型（Claude、GPT-5）的接入与调度能力成为竞争关键。

定价模式动荡：行业尚未形成稳定定价范式，按量付费与订阅制并存，成本控制成为产品可持续性的挑战。

开发者体验为王：与现有 IDE 生态的融合度、响应速度、上下文理解准确性决定用户留存。

POSITIONING

产品定位

差异化定位对照

为专业开发者打造：面向中高级开发者，提供深度代码库理解与 Agent 能力，而非零基础编程工具。

替代而非补充：基于 VS Code 分支构建，目标是成为开发者日常编码的主编辑器。

全流程覆盖：从代码补全（Tab）、自然语言编辑（Cmd+K）、多文件 Agent（Composer）到代码审查（Bugbot），覆盖编码全生命周期。

模型无关：接入多家前沿模型（OpenAI、Anthropic、Google、xAI），让用户按需选择，避免被单一模型锁定。

05
AI CAPABILITIES

AI 能力

底层技术与智能化能力
01

多模型接入

支持 Claude（Opus/Sonnet）、GPT-5、Gemini、Grok 等前沿模型，用户可切换或并行使用。

02

上下文工程

核心优势在于对项目代码库的索引与理解，支持「与整个代码库对话」，显著提升回答准确性。

03

Agent 能力

Composer 与云端 Agent 可自主规划并执行多步骤任务，如创建完整 Web 应用（前端+后端+数据库）。

04

模型调度策略

根据任务复杂度自动选择模型，平衡速度与质量（如快速请求与慢速请求分层）。

05

自定义与扩展

通过 MCP（模型上下文协议）、技能（Skills）和钩子（Hooks）扩展 AI 能力边界。

06

成本控制机制

采用「API 额度池」模式，不同模型消耗额度速度不同，让用户按需付费。

06
BUSINESS MODEL

商业模式

定价结构与变现路径

订阅制为主，按量付费为辅：个人版（Pro $20/月、Pro+ $60/月、Ultra $200/月）与团队版（$40/用户/月 + API 用量）并行。

双用量池设计：API 额度池（按模型推理量消耗）+ Auto/Composer 用量池（功能使用次数）。

免费版引流：Hobby 版提供有限额度，注册可享 14 天 Pro 试用（含 500 次高级模型对话），降低体验门槛。

定价策略调整：2025 年 8 月再次调整，团队版改为「$20 使用额度 + API 价格 + 服务费」，Auto 功能改为按 token 计费（输入 $1.25/1MT，输出 $6.00/1MT）。

成本结构挑战：模型推理成本是主要支出，定价调整反映其试图在用户价值与成本之间寻找平衡。
