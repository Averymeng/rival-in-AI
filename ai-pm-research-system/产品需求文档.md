## 1. 产品概述

### 1.1 产品背景
人工智能行业迭代极快，新产品、新模型、新融资、新争议层出不穷。AI 产品经理、创业者、研究员与投资人往往需要在极短时间内理解一个产品、一条赛道或一种竞争格局，并据此做出产品决策。然而相关信息高度分散于官方网站、产品博客、社区讨论、行业新闻、代码仓库等处，人工搜集与交叉验证成本极高，且极易出现信息滞后或模型幻觉。

### 1.2 产品定位
**一句话定位**：面向 AI 产品决策者的智能研究与报告生成系统——输入一个研究目标（产品 / 竞品 / 市场 / 选型 / 机会），产出结构化的、带证据来源的可视化研究报告。

定位关键词：**AI 垂直、决策导向、证据可追溯、可视化、单次研究闭环**。

### 1.3 目标用户
- **核心用户**：AI 产品经理（0–5 年经验），需要快速理解竞品与赛道以支撑立项、评审、周报。
- **次要用户**：AI 创业者、AI 行业研究员、关注 AI 赛道的投资人。

### 1.4 核心价值主张
1. 把"数小时的跨源调研"压缩为"一次提交 + 一次确认 + 一份报告"。
2. 证据可追溯，从机制上抑制大模型幻觉。
3. 输出结构化、可视化，可直接用于内部评审、立项决策与竞品跟踪。

## 2. 用户场景与痛点

### 2.1 典型场景（对应 5 类研究目标）
- **竞品对比**：「Kimi 和豆包在长文本能力上谁更强？」
- **产品分析**：「帮我系统分析一下可灵这个产品。」
- **市场扫描**：「AI 视频生成赛道现在有哪些主要玩家？」
- **产品选型**：「我们团队要选一个 AI 编程助手，怎么选？」
- **机会探索**：「AI 客服赛道还有哪些没被满足的机会？」

### 2.2 用户痛点
| 痛点 | 说明 |
|---|---|
| 信息分散、检索耗时 | 跨官网 / 社区 / 新闻 / 代码仓库搜集，效率低 |
| 来源不可信、结论无依据 | 大模型易编造，缺少来源绑定 |
| 缺乏统一分析框架 | 每次分析口径不一致，难以横向比较 |
| 产出非结构化 | 结论散落聊天记录，难以沉淀与复用 |

## 3. 产品目标与衡量指标

### 3.1 业务目标
让**单次研究任务**可一键完成，报告质量达到"可直接用于内部决策"的水平。

### 3.2 成功指标
- **北极星指标**：单次研究任务完成率 × 报告被采纳率。
- **效率指标**：从提交到出报告的中位时长。
- **质量指标**（v1.1 起量化）：来源覆盖率、事实可追溯率、用户满意度。

## 4. 功能需求

### 4.1 研究任务入口（5 类目标）
支持自然语言输入（「分析一下可灵」）与结构化输入（直接填 1–3 个对象名）。系统识别研究目标类型：
1. 产品分析
2. 竞品对比
3. 市场扫描
4. 产品选型
5. 机会探索

### 4.2 意图解析与澄清
- 解析产出：研究对象（1–3 个）、研究目标类型、限定维度（如「在 XX 方面」）、模式（对比模式 / 竞品分析模式）。
- 信息不足时，使用**选项式问题**补全，每次只问一个问题、优先给选项。
- **双模式**：
  - **对比模式**：用户点名 N 个对象 → 仅就这 N 个做正面对比，不引入外部竞品。
  - **竞品分析模式**：用户仅给 1 个主体 → 先深析该主体，再对比固定数量竞品（默认 5 个）。

### 4.3 研究简报（一次轻确认）
生成研究简报，包含：分析对象、对比对象（仅竞品分析模式以预置清单给初稿，确认后实搜扩充）、研究意图、选用维度、研究深度、输出形式。用户确认或编辑后才进入研究。**仅一次确认**，不做多次任务卡 / 框架双重确认。

### 4.4 实时检索与数据获取
每次研究**实时检索**，来源包括：官方网站、帮助文档、定价页、产品博客、版本发布说明、GitHub、Reddit、Product Hunt、行业新闻。
- 不做持久化知识库（v1.1 起评估）。
- 不做检索增强生成（v1.1 起评估）。

### 4.5 证据系统（纪律，非独立系统）
每条重要结论绑定：**结论、来源、时间、来源类型、可信度**。
报告结论分三类：
- **事实**：可核实的客观信息。
- **洞察**：基于事实的分析判断。
- **建议**：面向决策的行动建议。
来源缺失时标注「未查证」，严禁编造。

### 4.6 分析引擎（10 维度）
见《操作日志》第三节 10 维定稿：
市场与定位 / 产品与核心功能 / AI 能力 / 数据壁垒 / 技术与生态 / 商业模式与定价 / 用户体验 / 增长与运营 / 机会点 / 风险与短板。

### 4.7 可视化报告
- **报告章节（11 节）**：执行摘要 / 市场概览 / 产品定位 / 功能矩阵 / AI 能力 / 商业模式 / 增长 / 竞争格局 / SWOT / 机会 / 来源。
- **图表类型**：市场地图、功能矩阵、能力雷达图、时间线、用户口碑、机会地图、证据卡片。
- **第一版渲染**：采用"约定写法 → 自包含 HTML 渲染"（复用 AI 情报局原型），后续升级为交互式可视化。

### 4.8 报告交付
输出可视化网页 + 来源清单，支持归档与分享。

## 5. 非功能需求
- **性能**：标准深度下报告生成中位时长可控（目标随实测迭代）。
- **可靠性**：来源缺失时标注「未查证」，绝不编造数据 / 份额 / 融资。
- **安全合规**：仅使用公开信息，不抓取需登录授权的内容。
- **可扩展性**：维度、预置清单、图表类型做成可配置，便于未来扩展到 AI 之外的领域。

---

## 6. 产品边界（最小可行产品与后置）

### 6.1 最小可行产品范围
单次研究任务闭环：**输入 → 研究简报 → 检索 → 分析 → 可视化报告**。

### 6.2 明确不做（后置）
- 持久化产品知识库（AI 产品数据库）
- 检索增强生成（向量库 / 嵌入向量 / 文本分块）
- 流程编排框架（如 LangGraph）
- 量化评测体系
- 持续追踪 / 订阅 / 历史积累
- 多智能体并行调研

---

## 7. 竞争与差异化
| 对比对象 | 差异点 |
|---|---|
| 通用搜索引擎 | 提供统一分析框架 + 证据纪律，而非零散链接 |
| 通用 AI 助手 | 决策导向、结构化、可视化、可复用，而非一次性问答 |
| 付费行业报告 | 实时、按需、低成本，而非高价静态报告 |

---

## 8. 风险
| 风险 | 缓解措施 |
|---|---|
| 实时检索质量依赖模型与搜索能力 | 多源并行 + 交叉验证 + 来源优先级 |
| 信息时效性 | 报告标注数据时间，关键结论标来源时间 |
| 幻觉风险 | 证据纪律（结论-来源绑定、事实/洞察/建议分类、未查证标注） |
