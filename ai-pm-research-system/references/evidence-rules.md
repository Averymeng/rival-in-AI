# 证据纪律细则

## 1. 结论三类
- **事实**：可核实的客观信息（如「可灵由快手于 2024-06 发布」）。
- **洞察**：基于事实的分析判断（如「可灵凭运动仿真在专业人士中占优」）。
- **建议**：面向决策的行动建议（如「应补多模态 Agent 工作流」）。

## 2. 来源绑定
每条重要结论后附来源角标，报告末以来源卡片汇总：官网 / 帮助文档 / 定价页 / 博客 / 发布说明 / GitHub / Reddit / Product Hunt / Hacker News / 新闻 / 财报。

## 3. 未查证
无法核实或来源缺失的结论，内部标注「未查证」；报告页**不展示未查证列表**（保持干净），仅以角标提示缺失。

## 4. 禁止编造
严禁编造功能、价格、数据、份额、融资。来源存疑时降级为「未查证」而非臆测数值。

## 5. 评分口径
1–5 分制在图表图例中轻量说明（5=领先，3=平均，1=基本不覆盖），不单独成段、不作免责声明。
