# 可视化层 · 约定写法

报告以 Markdown 撰写，渲染器（`scripts/build_report.py`）识别以下约定，生成 ECharts 图表或 HTML 卡片。

## 1. 评分矩阵 → 能力雷达图 + 维度热力矩阵

首列为维度名、后续列为对比对象的表格，单元格为 1–5 数字：

```
| 维度 | 可灵 | Runway | 即梦 |
|---|---|---|---|
| AI 能力 | 5 | 5 | 4 |
| 商业模式 | 4 | 3 | 4 |
```

→ 自动生成雷达图（多对象叠加）+ 热力矩阵（色块）。

## 2. 定位 / 机会散点 → 市场地图 / 机会地图

表格含 `名称 | X | Y | 规模`，置于标题含「地图」的节下：

```
| 名称 | X | Y | 规模 |
|---|---|---|---|
| 可灵 | 4 | 5 | 3 |
| Runway | 5 | 4 | 2 |
```

X / Y 为 1–10 定位坐标（如 X=专业↔大众，Y=模型能力↔生态）。标题含「机会」时渲染为机会地图（空白区气泡）。

## 3. 时间线

```
## 时间线
- 2024-06：可灵 1.0 发布
- 2024-12：可灵 1.6 开放
```

## 4. 用户口碑

```
## 用户口碑
- 正面：「运动镜头最稳」—— 社区
- 负面：「高级会员贵」—— 评论
```

→ 正负向引用卡 + 情感条。

## 5. 优先级看板

```
Must：补多模态 Agent 能力
Should：做企业知识库集成
Could：探索端侧隐私对话
```

→ 三列优先级看板。

## 6. 摘要卡 / 来源卡

- `## 执行摘要` 下 3–6 条要点 → 摘要卡片。
- 含「来源 / 链接」的表格 → 来源卡片（跟随结论）。
