# 完整流程与示例

## 流程（5 步）

1. **意图解析**：自然语言 / 结构化输入 → 对象（1–3）、目标类型（5 类）、限定维度、模式。
2. **研究简报（一次轻确认）**：对象 / 对比对象 / 意图 / 维度 / 深度 / 输出。用户确认。
3. **实时检索**：按维度并行检索，每条结论带来源。
4. **撰写报告**：按 11 章节 + 约定写法写 Markdown，结论分事实 / 洞察 / 建议。
5. **渲染**：`scripts/build_report.py` 生成 ECharts 可视化 HTML。

## 示例 1 · 竞品对比模式

输入：「Kimi 和 豆包在长文本能力上谁强」

```
【研究简报】
· 分析对象：Kimi（月之暗面）、豆包（字节）
· 对比对象：上述 2 个（对比模式，不引入外部竞品）
· 研究意图：竞品对比（限定维度：AI 能力·长文本）
· 选用维度：全 10 维（长文本高亮）
· 深度：标准
· 输出：可视化报告
```

→ 报告重点答「长文本谁强」，其余维度简略；不拉元宝 / 文心等外部玩家。

## 示例 2 · 竞品分析模式

输入：「系统分析一下可灵」

```
【研究简报】
· 分析对象：可灵 AI（快手）
· 对比对象（预置初稿 5 个，确认后实搜扩充）：即梦 / Runway / Pika / 海螺视频 / PixVerse
· 研究意图：产品分析（展示机会点模块）
· 选用维度：全 10 维
· 深度：标准
· 输出：可视化报告
```

→ 先深析可灵，再对比 5 个竞品；报告含机会点模块。
