# 可视化约定写法（给 build_report.py）

报告用普通 Markdown 撰写，渲染脚本识别以下"约定写法"自动出图表。**请严格遵循表头与格式，否则图表无法生成。**

---

## 1. 评分矩阵 → 雷达图 + 热力矩阵
表格首列表头为「维度」，其余列表头为对象名，单元格为 1-5 整数或「未查证」。
```
| 维度 | Kimi | 豆包 |
| --- | --- | --- |
| 市场与定位 | 4 | 5 |
| 核心功能与AI能力 | 4 | 4 |
```
→ 渲染：多对象叠加**雷达图** + **热力矩阵**（色深=分值）。

## 2. 市场地图 → 定位散点
表格表头含「X轴」「Y轴」「规模」（规模可选，用于气泡大小）。坐标为 1-10 数值。
```
| 产品 | X轴(通用↔专业) | Y轴(流量生态↔模型能力) | 规模 |
| --- | --- | --- | --- |
| Kimi | 3 | 8 | 7 |
```
→ 渲染：**市场地图**（SVG 散点，含轴标签）。

## 3. 流程图
含 `→` 的步骤行（单独成段或用 `-` 列表）。
```
指令 → 分镜 → 生成 → 成片 → 发布
```
→ 渲染：**横向流程图**。

## 4. 优先级看板
行以 `Must:` / `Should:` / `Could:` 开头。
```
Must: 补多模态 Agent 能力
Should: 做企业知识库集成
Could: 探索端侧隐私对话
```
→ 渲染：三列**优先级看板**。

## 5. 摘要卡片
`## 一句话结论` 或 `## 核心发现` 下的 bullet 列表。
→ 渲染：每张 bullet 一张**摘要卡片**。

## 6. 来源卡片
含「来源」「链接」「说明」三列表头的表格。
```
| 来源 | 链接 | 说明 |
| --- | --- | --- |
| Kimi 官网 | https://... | 功能与定位 |
```
→ 渲染：**来源卡片**列表。

---

## 渲染命令
```bash
python3 scripts/build_report.py 报告.md --output 报告.html
```
输出为零依赖自包含 HTML（图表内联 SVG/CSS），可直接打开或部署。
