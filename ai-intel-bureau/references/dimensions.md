# 维度定义（7 个，不重合）

报告默认覆盖以下 7 个维度。它们已消除原有重叠（"产品定位⊂市场""AI能力⊂核心功能"已合并）。每维度下列出"看什么"，供查证与评分参考。

---

## 1. 市场与定位
- 目标用户（C 端/开发者/企业/垂直行业）
- 核心使用场景与锚点
- 品牌调性、赛道位置（通用 vs 垂直）
- 市场声量、增长态势

## 2. 核心功能与AI能力
- 主要功能清单（对 AI 产品，能力即功能，合并看）
- 底层模型（自研/开源/第三方）、画质、角色一致性、生成速度
- 多模态（文/图/音/视频）覆盖
- 独特能力标签（如长文本、Agent、实时）

## 3. 用户体验
- 易用性、上手成本
- 界面与交互
- 延迟、稳定性、可用性（是否有端/平台缺失）
- 客服与社区支持

## 4. 商业模式与定价
- 免费 / 订阅 / 积分边界
- 价格档位、变现方式
- 商业化成熟度（是否已盈利/收费）
- To B / To C 侧重

## 5. 增长与运营
- 获客渠道（应用商店/社媒/生态导流）
- 内容打法、裂变机制
- 社区运营、口碑
- 近期增长动作（融资、合作、发布）

## 6. 技术与生态
- 模型架构、技术壁垒
- API 开放度、插件/集成能力
- 开源情况、开发者生态
- 算力与基础设施

## 7. 风险与短板
- 合规与政策风险
- 关键依赖（如单一模型/渠道）
- 已知薄弱点、用户吐槽集中点
- 可持续性风险

---

## 评分口径模板
凡出现 1-5 分矩阵，先用一句说明标准，例如：
> 评分口径：各维度按公开资料 + 实测综合判断，5 = 赛道领先，3 = 平均水平，1 = 基本不覆盖。未查证项标「未查证」。
