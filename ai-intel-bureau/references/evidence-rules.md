# 证据纪律细则

本技能可信度的根基。无论何时都必须遵守。

## 1. 不编造
- 禁止虚构功能、价格、用户数、市场份额、融资额、技术参数。
- 拿不准的数字：**宁可不写，或写区间并标「约/未查证」**。

## 2. 三类结论分开
报告中明确区分：
- **【事实发现】**：可查证的客观事实（如"支持 200 万字上下文"，来源官网）。
- **【分析判断】**：你的推理与观点（如"长文本是其差异化壁垒"）。
- **【行动建议】**：给用户的下一步（如"应补多模态 Agent"）。

## 3. 评分必写口径（内部纪律，网页不单列）
任何 1-5 分矩阵前，分析时须确定评分标准，例如：5=领先，3=平均，1=基本不覆盖。
可在分数旁做最小化提示，但**不在页面单独成块展示**。

## 4. 来源可溯
- 关键结论尽量带来源（官网 / 报道 / 社区 / 财报 / GitHub / Reddit）。
- 来源在模块⑥以「来源卡片」汇总展示。

## 5. 标注「未查证」（内联，不单列）
- 无法核实或来源缺失的结论，在结论末尾内联标「未查证」角标。
- **不在网页单列「未查证项」列表**（避免页面像免责声明，保持简洁）。

## 6. 不夸大时效性
- AI 行业变化快，注明信息可能的时效边界（如"截至生成时"）。
- 若某结论来自模型记忆而非实时检索，应说明。
