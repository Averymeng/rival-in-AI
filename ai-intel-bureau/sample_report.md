# Kimi vs 豆包 竞品分析

## 一句话结论
- 豆包凭字节流量与免费策略在 C 端渗透更快；Kimi 以长文本+学术合规在垂直专业用户中更强；二者都尚未深耕「多模态 Agent 工作流」这一空白。

## 核心发现
- 豆包：免费 + 抖音导流，C 端 MAU 领先（来源：公开报道，未查证具体数）
- Kimi：长文本（200 万字）为差异化标签（来源：官网）
- 共同短板：端侧/隐私对话、企业知识库深度集成

### 优缺点对比
- Kimi：优点=长文本、学术合规；缺点=生态弱、C 端声量低
- 豆包：优点=免费、流量、生态；缺点=专业深度不足
